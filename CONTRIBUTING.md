# Contributing to Default Creds Web

This repository only contains the web frontend (Astro + Svelte). Bug fixes, UI improvements, and feature PRs are welcome here: fork, branch, and open a PR as usual.

Looking to **add or fix a credential**? That data lives in a separate repo: **[anotherhadi/default-creds](https://github.com/anotherhadi/default-creds)**. See its `CONTRIBUTING.md` for the YAML schema.

## Code of Conduct

By contributing, you agree to keep this repository a professional and ethical resource.
